# Електронні прилади та мікроелектроніка

Інтерактивний конспект лекцій і лабораторні роботи з дисципліни **«Електронні прилади та мікроелектроніка»** — Національний університет «Чернігівська політехніка», кафедра радіотехніки та відеоінформаційних систем (РТВС).

Викладач: д-р філософії **Пахалюк Богдан Петрович**.

Кожна лекція — це Jupyter-зошит з теорією, схемами, інтерактивними графіками (повзунки `ipywidgets`) і моделюванням реальних приладів у **PySpice + ngspice**. Лабораторні роботи виконуються не в TINA, а SPICE-моделюванням із чисельною обробкою результатів.

## Встановлення та запуск

Потрібні Python ≥ 3.10 і спільна бібліотека **ngspice** (перевірено з ngspice 42).

```bash
# ngspice (Ubuntu / Debian / WSL)
sudo apt install ngspice libngspice0

# Python-пакети
pip install PySpice numpy scipy matplotlib pandas ipywidgets schemdraw jupyterlab
```

У Windows без WSL встановіть ngspice командою `pyspice-post-installation --install-ngspice-dll`. Відкрийте зошит у JupyterLab або VS Code і виконайте всі комірки (*Run → Run All Cells*), щоб запрацювали інтерактивні повзунки.

Перевірені версії: PySpice 1.5, numpy 2.4, scipy 1.17, matplotlib 3.10, ipywidgets 8.1, schemdraw 0.23, pandas 3.0.

### Відомі особливості PySpice / ngspice

- **Повідомлення `Unsupported Ngspice version 42` і `Using SPARSE 1.3 as Direct Linear Solver`** — інформаційні, на результат не впливають; у зошитах їх приховано.
- **Пастка «атто»**: якщо задати струм як `0.001@u_A`, PySpice запише в netlist `0.001A`, а ngspice прочитає самотню `A` як префікс атто (10⁻¹⁸) — джерело мовчки стане нульовим. Постійні значення задавайте числами в амперах і вольтах, а амплітуди імпульсних джерел — з префіксом (`10@u_mA`).
- Параметр `TCV` (температурний коефіцієнт напруги пробою діода) у ngspice має розмірність В/°C і протилежний до звичного знак: $BV(T) = BV - TCV\,(T - T_{ном})$.

### Перегенерація лекцій

Лекції 1–9 і 11–13 генеруються сценаріями з `tools/build/`: вони збирають зошит із текстових і кодових комірок, виконують його (потрібні `nbclient` і `nbformat`) і зберігають з результатами в корені репозиторію.

```bash
pip install nbclient nbformat
cd tools/build
python3 L11.py           # перегенерувати й виконати Лекцію 11
```

Зображення для перевірки зберігаються в `tools/build/imgs/` (не відстежуються git). Лекцію 10 і лабораторні роботи редагують безпосередньо в зошитах.
